# 模型表现

第一阶段支持 **New API · 账户余额** 模板。选择账号，在详情中打开「模型表现」。首次打开只读取本地缓存；点击「更新」才查询站点。搜索、过滤、排序以及切换统计窗口不会自动访问站点。

## 查看与更新

1. 选择 24、72 或 168 小时的统计窗口。
2. 选择「站点优先」或「我的调用记录」，点击「更新」。查询沿用当前直连／代理选择和账号的总超时设置。
3. 搜索模型、过滤有流量的模型，或按成功率、延迟、首字延迟、输出速度、样本数排序。这些操作在本地完成。
4. 点击模型的趋势按钮，单独读取该模型的分组明细和趋势。

面板显示实际来源、窗口与读取时间。更新失败时保留上一次结果，并提示未更新；切换查询设置时，旧数据仍属于其原来的来源和窗口。关闭面板后，迟到的响应不会显示到另一个账号中。

归档账号可以查看已有缓存，不能更新。其他平台模板暂不提供此能力。

## 数据如何理解

| 来源 | 内容 | 限制 |
| --- | --- | --- |
| 站点公开流量统计 | 站点性能模块公布的成功率、延迟、输出速度及分组趋势 | 覆盖范围由站点决定，不一定是当前账号的调用；未公开的样本数显示未知 |
| 我的调用记录 | 当前管理凭据可以读取的消费和失败记录 | 最多读取 6 页、每页 100 条；只描述已返回且在窗口内的记录 |
| 模型目录 | 站点公布的模型名称、厂商和分组 | 目录不证明账号有权限，也不证明现在能调用 |

缺失指标显示「—」，不计作零或异常。历史表现不能保证下一次请求成功。个人日志的输出速度由输出 Token 和请求总时长估算，不能直接与站点生成阶段 TPS 比较。旧版成功率序列没有时间戳时，面板明确提示采样时间未知。

达到采样上限、分页中断、返回分页信息不一致或数据超出显示上限时，会提示不完整。最多展示 500 个模型、每模型 32 个分组和 168 个趋势点。

## 接口与凭据

使用账号已有的管理接口根地址和管理令牌。模型 API Key 与账户管理令牌用途不同。初次读取公开接口省略凭据；公开接口返回 HTTP 401 时，最多追加一次管理凭据请求。

查询固定使用只读 GET 接口：`/api/status`、`/api/pricing`、`/api/perf-metrics/summary`、`/api/perf-metrics`、`/api/log/self`。根地址的子路径前缀保留。仅性能接口返回 HTTP 404 时，站点优先模式才自动改读个人日志；权限错误单独显示，也可以手动选择个人日志。

本阶段没有签到、模型推理请求、保活或自动轮询。余额、余额快照、查询诊断和 JSON 备份格式保持原有用途。

## 缓存与验证

独立缓存仅保存有界的数值聚合和展示字段，不保存原始调用日志、提示词、IP 或令牌名称。删除账号会删除缓存；更换连接配置或凭据会使旧缓存失效。设置页 JSON 备份不包含模型缓存，迁移后可以重新点击更新。

专项浏览器验收：

```powershell
npm run test:model-insight -- --ready
```

验收重新构建隔离的源码快照，使用临时数据库和本地合成站点，覆盖来源、趋势、错误、采样、缓存和手机浅深主题。输出位于 `output/playwright/model-insight/`。没有 `--ready` 时不构建、不启动服务。

当前验证范围是合成夹具；各实际站点的版本、性能模块开关和令牌权限仍需在自己的部署中点击更新确认。

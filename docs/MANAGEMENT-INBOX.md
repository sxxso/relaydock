# 待处理站点与批量余额查询

工具栏下方的待处理筛选提供低余额、记录过期、余额未知及最近查询失败。数量基于当前搜索、分组、单位、收藏和归档范围计算；各入口互斥，切换时清除旧的低余额和记录年龄条件，其余条件保留。“全部”只清除这组待处理条件。

记录过期指已有余额且记录时间至少七天，或记录时间缺失/无效。余额未知单独列出，不视为零。查询失败依据最近余额查询结果，不等同于站点离线。条件可保存为视图，旧视图默认不启用待处理条件。

点击刷新余额会先显示范围确认。有勾选项时使用当前筛选结果里的勾选账号，否则使用当前筛选结果。手动记录、无凭据、已归档和正在查询的账号会排除。确认后沿用面板所示线路，以最多三路并发执行。

取消排队只停止尚未发出的请求；已发出的请求继续等待响应并记录结果。收起面板不会取消，点击工具栏下的“查询进度”或“查询结果”可重新打开。仅重试失败项由用户点击触发，成功项与取消项不会自动重试。再次开始或重试前会检查账号是否仍可查询；会话失效和退出登录停止后续排队。

结果仅保留在当前页面会话，刷新页面后不保留任务面板；已记录的余额和查询诊断仍由原存储流程保存。没有定时任务、轮询或自动访问站点。

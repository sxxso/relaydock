# 水墨群岛交互约定

2026-10-02。保留站点群岛的信息布局，只优化地图视角；节点不支持摆位或拖拽改分组。

## 外观

- 顶栏右侧的月亮／太阳按钮保存浅深主题；设置中仍可选跟随系统。
- 新主题以约 520ms 的斜向纸幕从右上揭开至左下，浅到深、深到浅使用相同方向。浏览器不支持 View Transition 时直接切换。
- `src/lib/appearance.ts` 管理快照生命周期；旧回调不能覆盖较新的选择，未初始化和隐藏页面不播放。CSS 仅在揭幕期间关闭普通颜色过渡，避免捕获半成品主题。
- 设置写入串行保护，失败回滚并显示真实错误；读取外观偏好使用设置版本，不允许保存之前或保存期间的旧响应覆盖界面。

## 选择控件

- `AtlasSelect` 只借助 Radix 的键盘、焦点、定位和触屏行为，纸边、松绿印记和菜单展开反馈均为本项目样式，不使用现成主题包。
- 支持箭头、键盘输入快速定位、Enter/Space、Esc；关闭后回到触发器。选项标签可换行，菜单有视口碰撞保护，长列表可滚动。
- 空字符串选项统一编码，历史页的“全部账号”不会与真实值冲突。数值单位与业务接口不改变。

## 地图性能与手势

- d3 处理手势和缩放；变换保存在 ref 中，由 requestAnimationFrame 合并更新 SVG。缩放比例直接更新文本，React 只在余额标签显示阈值变化或手势首尾时提交。
- 可从节点起拖动视角；位移超过 5px 不触发节点点击，轻微点击抖动仍能选中。
- 左键点击地图空白主动清除遗留文字选区。只有 SVG 地图禁止选字，详情、网址和正文仍可复制。
- 手势会打断旧镜头；切页卸载释放窗口拖动监听、选区拦截和申请的帧。外部查询策略完全不变。

## 动效预算与无障碍

- 菜单约 160ms、视图约 180ms、详情约 220ms；收藏印记、按钮按压和真实余额记录提供短反馈。不滚动虚构金额。
- 没有呼吸灯、漂浮节点、循环粒子或常驻帧循环。Canvas 仅在鼠标动作后运行约 550ms，拖动时暂停，静置结束即停帧。
- 关闭动效或系统减少动效时，不创建主题快照，并取消 Canvas 的监听和帧；触屏不运行鼠标擦显。真实请求的忙碌指示不代表装饰动画或站点可用率。
- 参考接口文档：[View Transition API](https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API/Using)、[Radix Select](https://www.radix-ui.com/primitives/docs/components/select)。

## 验证

`npm test`、`npm run typecheck`、`npm run build`、`npm run test:e2e`、`npm run test:interactions`。

两套浏览器回归都创建临时数据库，不使用或写入真实账号。地图性能断言使用测试注入的 React DevTools 提交计数，不能等同于所有设备上的 FPS；最终数值查看 `output/playwright/interactions/verification.json`。截图中的余额均为测试夹具。

# New API 签到与月历

第二阶段提供标准 New API 的手动签到、明确范围的批量签到、站点月历与最近操作记录。仅在点击时访问站点，没有定时任务、保活或模型推理。

## 单账号

打开 New API 账号详情的「签到与月历」。打开面板只读取 Atlas 本地缓存；首次显示未知。点击「查询签到状态」读取站点开关、今日状态和月份记录。月份切换也只读取缓存，再点击查询才读取该月站点记录。

「立即签到」会先查询站点今日状态，未签到且接口可用时提交一次。默认不刷新余额；勾选「成功后刷新余额」会在签到成功后追加余额查询。余额读取失败时签到仍然成功，旧余额保留。签到奖励不能直接加到旧余额。

本地缓存显示已签到时，会提示缓存可能已过期；跨日后点击「查询签到状态」确认今日情况。面板不会自动查询或按客户端时区推断状态失效。

日历的日期来自站点。当前展示月份与“今日已签”是独立信息：查看往月时，今日状态仍由站点返回。默认月份在有记录时取站点记录月份，无记录且上游没有月份字段时只能使用客户端请求月份；界面标明来源，不能据此推断站点时区。

已确认账号换算系数时，日历奖励优先显示换算金额，例如 12,500 配额 ÷ 10,000 配额/USD 显示 `$1.25`。悬浮提示、无障碍文本和操作记录保留原始配额；未设置有效换算时明确显示配额，不猜测系数。金额最多六位小数，极小正数显示小于精度阈值，零和未知分开。月签到次数与历史累计次数、额度分别展示，不把历史累计叫作本月奖励，不跨站合计。

## 批量

工具栏「批量签到」显示预览。有选中账号时使用选中范围，否则使用当前筛选结果；打开时固定账号列表，最多 500 项。点击「开始签到」才执行。

预览只读取本地缓存，已签缓存显示「缓存已签，执行时再次核对」，待确认状态单独提示。缓存加载失败或没有记录时保持未知；所有固定账号 ID 都交给服务端重新核对，不按旧缓存排除账号。

服务端逐账号核对凭据、平台、归档和今日状态，跳过已签、归档、不支持、缺凭据、忙碌与同站同用户重复卡片。总并发最多 3，同站串行，开始时固定直连／代理线路。结果按账号显示，不跨站汇总奖励。

## 结果待确认与网页登录

提交后遇到超时、断连或无法确认的响应会显示「结果待确认」。提交前已保存待确认记录，因此重启后也不会自动重复 POST。后续查询确认今日已签后才能解除；查询仍未签不证明此前提交没有生效，继续保留待确认提示，到站点核对。

管理令牌／个人访问令牌必须具备签到读取与执行权限。本阶段还需要填写站点用户 ID，以便确认重复账号身份并保留跨卡片的待确认状态；新版站点即使允许免用户 ID 读取余额，Atlas 签到仍需要这项身份配置。余额可读不代表允许签到；模型 API Key 不能当作管理令牌。需要 Cookie 会话或 Turnstile 的站点显示「打开站点完成」，在目标网页操作后回到 Atlas 查询状态。Atlas 不复制浏览器登录会话，也不绕过验证码。

## 本地记录

签到状态、站点月份记录、最近 100 条操作结果独立保存，不混入余额快照。只存白名单数值、日期和固定提示，不存站点原始响应或管理令牌。连接配置／凭据变化会使旧缓存失效，名称／分组变化不影响身份。账号删除会清理对应缓存和操作记录；为避免删除重建卡片后重复提交，未确认身份的屏障继续保留。现有数据备份格式保持兼容，本阶段签到缓存和操作记录不随数据备份导出。

## 验证

`npm run test:checkin -- --ready` 从白名单源码构建全新生产版本，使用临时 SQLite、随机回环端口与合成站点，验证操作和截图；不使用部署 `.env`、真实账号或旧 `.next`。无 `--ready` 只显示提示。

第二阶段冻结版本的本地合成浏览器验收 21 项通过，包括缓存不访问外站、手动／批量操作、防重复、余额刷新成功／失败、月历、键盘与 375／768／1440 浅深主题，历史机器报告为 `output/checkin-acceptance.json`。本轮增加换算奖励与原始配额断言；最新全量测试与构建记录见 [当前状态](STATUS.md)。实站版本和令牌权限尚未验证；没有提交真实账号签到。

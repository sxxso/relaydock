# 特效与地图外观

在「设置」的外观区域选择「特效颜色」：跟随主题、海蓝、青绿、琥珀、紫色或自定义颜色。自定义使用系统选色器，保存六位 HEX；只调整装饰墨迹和几何加载图形，错误与余额告警色不变。「恢复特效默认设置」恢复跟随主题和 100% 特效浓度。

「特效浓度」「底图浓度」支持 0–100%。拖动时更新百分比，特效浓度还会改变设置中的墨迹预览；释放、键盘操作完成或失焦后保存并应用到地图。保存失败会回退并提示。0% 隐藏地图墨迹或底图纹理，底图浓度不影响账号、群岛与文字，特效浓度不隐藏加载图形。

地图底图在地图菜单和设置中都可切换：素纸、点阵、方格、十字坐标、等高线，以及新增的疏朗海图。海图使用淡坐标和静态海流曲线；等高线采用连续周期曲线，方格包含主辅网格。「底图密度」提供疏朗、标准、细密。缩小时自动降低细节，图案随相机平移，在负坐标区域仍连续平铺。

已有底图选择保留。新字段在旧设置、旧备份中缺失时，自动采用跟随主题、浓度 100%、标准密度；可随正常设置备份恢复。

加载图形循环经过方形、菱形、圆形和群岛组合，只在真实加载期间展示。数据准备好立即显示工作台，不增加等待时间。关闭装饰动效或系统选择减少动效时显示静态图形；地图墨迹仍遵守触屏、拖动与减少动效限制。

本功能源码已接入。运行中的部署需另外更新后才能看到；本轮验收使用隔离合成数据，未修改当前运行版本。

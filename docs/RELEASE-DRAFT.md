# RelayDock 首次公开说明草稿

> 草稿，未创建 GitHub Release，版本标签待确定。发布时应附当时实际 CI 与 Docker 结果。

RelayDock（汇站 Atlas）是自托管的 API 站点与多账号余额工作台。通过群岛地图或紧凑列表整理分组、收藏、标签与归档；主动记录和查询余额，保留来源、时间与历史。

- 七个平台模板和声明式字段映射；账户金额、令牌额度与配额按各自口径隔离。
- 单管理员认证、加密保存查询凭据、受控出站；只在明确操作时访问目标站点，没有后台余额轮询。
- New API 模型表现、手动签到与月历、邀请链接；打开面板读取缓存，点击更新才访问站点。
- 保存视图、短时撤销、分组位置、低余额提示、数据备份与恢复；JSON 备份不含查询凭据。
- 纸面几何界面、浅深主题、手机布局、减少动效支持；截图全部来自合成数据运行。
- Node.js 本机运行与 Docker/Compose 配置，离线部署自检、合成测试和 GitHub CI。

项目源码采用 MIT，版权署名 cjmarklll。第三方组件保留各自许可证，详见 THIRD-PARTY-NOTICES.md。

首次公开的验证边界：七个平台实站未验证；当前本机未完成 Docker 实测，首次 GitHub CI 待实际运行；本地合成验证不能替代这些检查。此版本不承诺对任意中转站的接口兼容。

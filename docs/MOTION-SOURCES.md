# 动效来源与许可

站点页像素小岛向导使用项目内原创 SVG 像素几何与 CSS 动画，视觉参考像素桌面伙伴的方块造型；未复制 Claude 的角色资源、代码或商标。向导信息来自已有本地档案，不调用语言模型或站点接口。海图方向标记及细水纹墨迹同为项目内绘制。

登录角色改编自 https://github.com/huangj17/login-animated-characters （作者 huangj17，README 声明 MIT），上游 https://github.com/arsh342/careercompass 。将交互迁移为 React 状态，保留几何角色、鼠标跟随、眨眼与密码回避的设计，增加减少动效适配。

按钮光环分层参考 Magic UI ShimmerButton：https://github.com/magicuidesign/magicui 。未引入远程字体、脚本或运行时网络资源。

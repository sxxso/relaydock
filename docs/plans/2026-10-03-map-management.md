# 地图与批量管理 · 第四阶段实施计划

> For agent: 按 Superpowers 执行计划、TDD、独立评审及完成前验证实施。用户已批准产品路线并明确开始第四阶段。只修改 relaydock；不提交或推送。

**目标：** 让站点群岛支持查找、导航和批量整理，保持真实余额语义与点击查询约束。
**架构：** 全量档案生成确定性几何，筛选结果是共享 ID 集合而不是重新布局的输入。地图折叠是工作区暂存状态，定位小窗与网格共用按帧更新的镜头，不增加持续循环。批量元信息通过白名单命令在 SQLite 事务中保存。
**技术：** 现有 Next.js / React / TypeScript / d3-zoom / SVG / SQLite / Vitest / Playwright，无新增依赖。

## 设计与边界

- 继续暖纸、墨绿、宋体分组与清晰金额；管理工具像地图旁的索引，不变成通用仪表盘卡片。
- 搜索/币种/分组/收藏/关注结果在地图轻度淡化其他节点，列表只列匹配项。计数、刷新范围和批量范围仍依据同一个匹配集合。档案范围外的节点不展示。零匹配保留地图与「无匹配」反馈。
- 地图基于全量账号 ID/分组生成坐标。余额、排序、搜索、折叠不更改几何；真正新增、删除、改分组可改变布局。不承诺结构变化下原位置恒定。
- 分组索引提供聚焦与折叠/展开；折叠保留原岛和计数，隐藏子节点。定位账号先展开其分组。切换列表保留筛选、选中账号及折叠状态。
- 定位小窗显示各岛、当前视口与选中点；点击/拖动定位、方向键移动，Home 全图。主要镜头按帧修改 SVG/ref，不随每帧重绘全部节点。
- 点阵/方格/十字/等高线以二次幂层级调整采样间距，远景不过密、近景不空洞。装饰在静置时停止，触屏/关闭动效/减少动效禁用镜头动画。
- 大组使用更多列，适当降低最小缩放以容纳 200/500 档案。缩远隐藏详细金额，名称与金额保留可访问标签，放大或列表查看。
- 列表批量模式独立于详情选择。最多 500 项，只选择当前匹配账号；筛选变化移除隐藏项，地图/列表切换保留仍可见选项。显示明确范围与已选数量。
- 分组、标签添加/移除/替换、归档/取消归档；替换和归档明确确认。没有批量删除/余额改写/查询。服务器只修改指定元信息，保留快照、诊断、凭据和其他档案字段；不存在/超限/非法/忙碌均不部分写入。
- POST /api/accounts/batch：`{ ids, operation }`，operation 为 `{kind:'group',group}` / `{kind:'tags',mode:'add'|'remove'|'replace',tags}` / `{kind:'archive',archived}`；返回 `{accounts}`。登录、来源与 CSRF 校验沿用，正在查询的任一账号导致 409。

# 分组颜色与灵动工作台

用户确认：分组自定义颜色、样式清理、工具栏收纳、加载骨架；强调更丰富灵动的 Bauhaus 动效。

## 设计
- 保留暖纸面、海军蓝文字和现有字体；八个实体印刷色预设、原生取色器、HEX 输入。不要新增霓虹、玻璃或渐变光效。
- 分组筛选旁提供「分组颜色」入口，低频「分组改名」收进更多筛选。弹窗左对齐字段，八色方形色票，两种实际预览（地图节点、列表头像）。选择时几何元素响应，实时在弹窗内预览；保存后更新整个工作台，取消不写入。
- 自定义颜色不改动余额警示语义。自动选择文字颜色达到 4.5:1；分组地块与小地图用颜色混合的淡色块，文字仍用主题前景。
- 单独的 SQLite meta `groupColors` 保存 revision 与 `{name,color}` 数组，防止主题保存互相覆盖。严格 HEX 校验、乐观并发、归档分组支持、重命名事务迁移、备份带颜色；旧备份没有字段时保留现有颜色。
- 地图、列表、详情头像、小地图及搜索结果共用颜色解析函数；自定义色跨主题保持相同值。
- 工具栏优先搜索、分组、颜色、币种、收藏、视图和查询；改名进入现有更多面板，保存视图保留可发现性。
- 加载使用与工作台一致的 header / toolbar / map 占位，中央几何加载器；不伪造余额或实际账户。首次数据读取完成前不闪现空状态。
- 动效重点：色票盖章、预览几何组装、视图切换的几何揭幕、节点选中回弹、展开面板、按钮按压、记录确认。动画不改变 d3 所管理的节点/世界坐标，只作用于子元素；没有空闲循环，只有加载器循环。
- 单一动效关闭机制，系统 reduced-motion 与应用关闭都禁用非必要运动，包括移除旧的 spinner 例外。

## 验收
真实 SQLite/API 测试颜色持久化、严格校验、事务、改名、备份、并发；浏览器验证预览、取消、保存、恢复默认、刷新、浅深主题、手机、文字对比度与关闭动效；截图人工检查。使用隔离 fixture，不修改用户数据。

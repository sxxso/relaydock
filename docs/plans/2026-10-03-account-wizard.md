# 第二阶段：新增站点向导实施计划

> For agent: 使用 Superpowers 执行计划 / TDD / 评审 / 完成前验证。用户已批准五阶段路线并要求完成第二阶段；不启动第三阶段，不提交 Git。

**目标：** 新增由“平台 → 地址与凭据 → 点击测试 → 确认单位 → 保存”引导，减轻一次性表单负担。
**架构：** 编辑保留既有表单。新增使用受控内存草稿和五步向导；`POST /api/query/test` 仅验证草稿，复用已有查询与脱敏诊断路径，不创建账号、快照或凭据记录。保存仍调用账户 CRUD，无外部查询。
**技术：** React、Radix Dialog / AtlasSelect、Zod、现有 Node 出站保护、SQLite、Vitest、Playwright。

## 设计与不变项

- 延续纸白 #FCFAF8、墨黑 #26251E、暖灰 #F3F0EF、松绿 #617C71。编号只用于实际步骤；平台选项为可键盘操作的分组选择，不添加营销区或循环动画。
- 测试仅主动点击按钮触发；只允许登录 + CSRF POST。草稿忙碌保护按会话控制；不自动重试，沿用共享超时及 SSRF 防护。请求体仅接受查询必需字段，凭据不能进 URL / localStorage / 日志 / 报告。
- 平台从用户选择，不根据域名推断。New API 管理令牌查账户；模型 API Key 查单个令牌。原始配额测试与最终换算分开，未确认系数仍为原始配额，不混入货币总额。
- 改查询字段使原测试失效；返回步骤保留输入。切换平台清空凭据与接口根地址，防止误送旧密钥。修改非查询档案信息不要求重复请求。
- 测试成功只供确认，无自动写余额；初始余额仅手动记录时可填，未知保持 null。失败可回去修正，也可勾选确认后保存“未验证”配置，保存不查询。
- 单位 / 查询口径需明确确认；平台固有货币不任意改写。New API 换算预览来自本次真实 rawQuota，用精确十进制，不再次请求。
- 编辑表单保持兼容；不重置真实账号、密码、.env.local、DoH、代理或数据库。

# 已有分组选择与整岛移动

## 设计

- 复用 AtlasSelect 的纸面/松绿菜单，新增与编辑均列出所有已保存分组（含归档账号分组），允许「新建分组」；选择不查询、不创建空分组。保留当前值与未分组。
- 拖住岛内标题条移动整组；标题握柄与轻边界反馈，不增加常驻动画。空白仍平移，节点仍排序/改组。5px 阈值区分点击，Esc/捕获丢失取消。
- 指针投影使用 SVG CTM + 当前镜头；仅更新一个岛和其节点的 SVG transform，每帧至多一次，不逐帧重渲染站点树。松手才写入，保持内部相对位置/余额/历史不变。
- 坐标为非负有界世界坐标；持久化绝对位置，不因新增另一分组重新移动已摆放的岛。默认组保留自动布局；允许用户自行重叠，不做力导向/自动避让。
- 独立 SQLite meta 存储 revision + 位置数组；受登录/CSRF保护、事务内修订校验。失败回滚，旧读取不可覆盖新保存；v3 JSON 备份可选 groupPositions，兼容旧备份。
- 标题获得焦点后方向键移动（Shift 加大步长），Home 恢复该组自动布局；折叠岛也可移动。缩略图/搜索定位使用新坐标；触屏与减少动效保持功能。

## 实施/验收

1. 分组菜单数据、位置布局、API鉴权/边界/冲突/重启/备份回归先 RED。
2. 服务端位置事务与备份；共享分组选择控件接新增/编辑。
3. 地图低成本整组拖拽、键盘替代及取消、乐观保存/回滚。
4. 隔离生产浏览器覆盖菜单、拖拽/平移/缩放/取消/失败/刷新、折叠/键盘/触屏、375/768/1440浅深主题与无查询。
5. 全套单元、typecheck/build；重新执行线路与旧站点拖拽浏览器验收。真实配置/数据不改，不查询真实站点。

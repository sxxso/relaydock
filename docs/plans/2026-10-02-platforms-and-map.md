# 多平台查询与地图材质完善

用户已批准推荐方案；当前故障为 New API 查询超时。仅修改 relaydock，不重置实际数据、凭据或密码，不提交／推送。

后续确认：用户只希望加入可选 Cloudflare DNS-over-HTTPS 配置，不在本机启用；明确暂不加入代理支持。系统 DNS 与公共解析结果不一致、直连被重置、Windows 系统代理开启的检查仅使用公开状态地址，没有读取或请求真实凭据。

## 设计与约束
- 采用 CC Switch 的平台模板与可配置查询思路，不执行任意 JavaScript。预设手动、New API、通用、DeepSeek、OpenRouter、SiliconFlow 兼容接口，以及声明式自定义 GET 查询。
- 自定义为同源相对路径、Bearer/API-Key 头认证、余额字段路径、可选扣减字段与除数；禁止脚本、跨源路径、URL 查询中的凭据和任意请求头。
- SiliconFlow 官方 /user/info 已停用，只标记兼容旧接口，不宣称官方可用。OpenRouter 账户余额需管理 Key，不把普通 Key 的额度冒充账户余额。
- 查询仅点击触发，默认 10 秒，可选 20／30 秒；保留并发 3、无自动重试、安全 DNS 固定和重定向拒绝。阶段化错误不带令牌、原始响应或完整请求 URL。连接测试不写余额快照。
- 原有账户 JSON 增加默认查询配置；旧备份仍可导入，新字段随无凭据备份保存。失败不清零。
- 地图添加纸面、点阵、方格、十字、等高线，以静态 SVG 原创图案跟随镜头；不加常驻动画。选择持久化并包含备份，默认点阵；现有地形布局与手势不改变。
- 下拉框保持 Radix 行为层，细化纸面、图标、标题分隔、选中栏和说明；保持键盘、长标签、触屏及减少动效。

## 实施步骤
1. 查询 schema／适配器／路径／超时与向后兼容写失败测试，再实现。
2. 扩展受保护接口与表单、测试诊断；验证 HTTP、超时、错误保留余额、凭据脱敏。
3. 独立选择组件视觉完善；新增地图背景与设置入口，测试持久化。
4. 全量单元、类型、生产构建；隔离 Playwright 检查多平台夹具、预览不写余额、背景切换、移动菜单，检查截图。
5. 更新中文文档和状态，明确真实站点联调／Docker限制。

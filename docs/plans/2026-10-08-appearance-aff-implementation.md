# 视觉设置与 New API 邀请链接实施

> 使用 Superpowers 第 5/6 节分领域实施并完成规格、质量及最终独立复审。用户已批准方案并明确排除 Sub2API。

**Goal:** 实现持久化装饰选色、几何加载、可调地图底图和 New API 邀请链接。
**Architecture:** 沿用 settings、SVG/D3 与加密管理凭据；邀请资料按账号缓存，外站获取由用户按钮触发。视觉设置互不影响告警色，保留原默认值。只用合成数据库和回环站点验收，不修改运行部署或 Git 状态。
**Tech Stack:** Next/React/CSS/Canvas/SVG/Zod/SQLite/Vitest/现有 Playwright 隔离构建。

1. 外观域：settings 增加 inkColor（null 跟随主题或六位 HEX）、inkOpacity（0–100，默认100）、mapOpacity（0–100，默认100）、mapDensity（sparse/standard/dense，默认standard）；mapBackground 增加 sea。旧数据默认兼容，设置在外观页即时预览/保存/恢复。Canvas 即时响应颜色与浓度，不依赖 resize；动效关闭、触屏、减少动效与拖动清空保留。加载图形方形→菱形→圆形→群岛组合，不延迟数据展示。
2. 底图域：新增疏朗海图，精简等高线和主辅测绘纸；浓度/密度属性接到地图，纹理随相机且负坐标无接缝，缩小时抽样。默认选项保留，浅深/手机/远近缩放截图比较。
3. 邀请域：独立 New API 接口适配；主动获取并提示缺码可能生成；邀请码/链接/时间/自动或手动来源按账号保存，支持复制和编辑完整注册链接。使用管理根地址+PAT+用户ID、现有安全出站与代理，拒绝模型Key模板/归档/缺凭据；旧版404/HTML/身份失效/迟到响应不误保存、不泄漏响应秘密；本地缓存GET不请求外站。
4. 验收：先有意义的 RED/GREEN；全套开启地图手势与非增量类型检查；全新白名单源码构建与合成浏览器检查，无真实站点请求；规格→质量→最终独立审查。更新使用文档和机器验收证据。

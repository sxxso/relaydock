# 水墨群岛交互完善实施计划

> 按 Superpowers 的计划执行、TDD 和验证流程在当前会话实施；不提交或推送。

**目标：** 保留页面布局与数据架构，让主题、选择控件、地图平移和操作反馈更有质感。
**已确认范围：** 用户批准右上向左下主题揭幕、顶栏按钮、定制选择控件；仅优化地图平移，不增加拖拽分组或节点摆位。
**架构：** 主题用渐进增强的 View Transition；选择控件用 Radix 的无样式行为和原创纸面样式；地图继续使用 d3-zoom，手势帧不驱动整张节点树渲染。短时 CSS/WAAPI 动效统一受动效设置和系统减少动效控制。

## 设计约束

- 保留纸白 #FCFAF8、墨黑 #26251E、暖灰 #F3F0EF、松绿 #617C71 与暖炭深色主题。
- 系统无衬线负责控件，宋体仅用于分组名称，数字保持等宽排版。
- 控件使用纸边、松绿印记、清晰的选中线；不套通用渐变卡片，不改变信息布局。
- 主题约 520ms 揭幕，菜单约 160ms，详情约 220ms，视图约 180ms；所有动效由操作触发，静置不产生循环。
- 不支持 View Transition 时直接切换；减少动效、关闭动效时禁用揭幕与镜头过渡。
- 不更改数据目录、管理员密码、同步策略、备份或任何外部请求规则。

## 执行顺序与验收

1. 新增 scripts/verify-interactions.ts，隔离 SQLite，先运行证明旧版主题入口、菜单和左键取消的失败。
2. 新建 src/components/atlas-select.tsx 与独立样式；替换筛选、历史和表单的 native select，保留标签、键盘、Esc、触屏、长选项可读性。
3. 新建主题控制逻辑与回归单测；顶栏按钮持久化主题，失败回滚，快速操作不产生并行设置写入；系统主题与设置页保持一致。
4. AtlasMap 使用 transform ref 与帧合并，平移不重渲染节点，保留点击距离阈值和稳定布局；空白左键主动清除遗留文字选区，输入框与可复制文本不禁选。
5. 补菜单开闭、主题图标、视图滑块、详情、收藏/保存的短动效；静置 Canvas 停帧；减少动效或关闭动效时无装饰动画。
6. 更新旧 E2E 的 select 操作并验证：npm test、npm run typecheck、npm run build、npm run test:e2e、npx tsx scripts/verify-interactions.ts。
7. 检查 375/768/1440 浅深截图、菜单和 50 账号地图；写 docs/STATUS.md，启动本机预览。所有截图示例数据只保存在隔离夹具中。

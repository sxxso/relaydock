# 分组拖拽与余额查询兼容

## 用户需求与边界

- 分组名称放在岛内首行中央；节点可组内排序、跨组拖动，结果持久化。空白拖动继续平移。
- 显式部署 HTTP/HTTPS CONNECT 代理，默认关闭，不读取系统代理，不改变真实配置。
- 自定义 `/v1/usage` 预设按 remaining / quota.remaining / balance 的 nullish 顺序取值，读取 unit / quota.unit / USD，并校验 is_active / isValid。
- New API 保留账户管理令牌、用户 ID、GET /api/user/self，500000 换算必须确认；失败不覆盖余额。
- 不执行用户 JavaScript、不后台轮询、不自动重试、DoH 不启用。代理连接目标仍固定已校验 IP，TLS 验证原站域名。

# 单位选择与工作台密度

用户已批准直接拓宽并收紧布局，不增加密度切换控件。

## 设计与边界

- 编辑单位复用 AtlasSelect：USD、CNY、积分、自定义；仅自定义显示输入框，并保留已有自定义单位。
- New API 令牌与 DeepSeek 只选 USD/CNY；OpenRouter 固定 USD，SiliconFlow 固定 CNY，和添加向导一致。
- 更改档案单位不转换已有快照，不触发接口查询；说明旧余额单位保留。
- 桌面站点工作台取消 1536px 限宽，边距 24px；收紧顶部与列表行距，不压小文字、截断长名称。
- 列表记录来源/相对时间并排，查询结果仍保留；手机继续完整展示，历史/设置保留阅读限宽。

3. 新生产构建验证预设/自定义持久化、平台限制、旧快照不变、零外部查询。

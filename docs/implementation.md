# 汇站 Atlas 实施约束

已确认：独立部署、单管理员、只在点击时同步、D 水墨群岛、MiMo Coder 的暖纸面与局部擦显作为材质和反馈参考。原创纹理，不使用小米素材和源码。

实施顺序：

1. 红绿测试建立金额、稳定布局、输入校验、加密与 SSRF 基础。
2. SQLite/Drizzle 持久化、管理员会话/CSRF、账号/余额/备份接口。
3. New API 适配：用户管理令牌，可选用户 ID，配额确认，DNS 固定解析、不跟随重定向。
4. 中文响应式界面：地图、列表、详情、编辑、历史、设置、导入预览。
5. 动效：400ms 墨岛入场、550ms 背景擦显、300ms 相机、220ms 详情；静置停帧；触屏与减少动效禁用装饰。
6. 单元/接口/E2E、375/768/1440 浅深色截图、构建、部署说明。

无真实站点密钥时仅验证夹具；没有 Docker 时不声称容器实测。所有真实数据和凭据均保存在被 Git 忽略的 data 目录。不能把示例账号写入真实库。

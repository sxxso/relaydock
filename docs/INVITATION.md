# New API 邀请链接

在 New API 账号详情点击「邀请链接」。打开、重开和刷新页面只读取本地缓存，不访问站点。Sub2API 未接入。

先在账号档案填写管理 PAT 和用户 ID，然后主动点击「获取邀请码」。接口固定为管理根地址下的 `GET /api/user/aff`，沿用余额查询的直连／代理选择与受控出站。模型调用 Key 不能替代管理 PAT。尚无邀请码时，New API 可能生成并保存一个；面板会在按钮操作前说明。没有后台轮询或自动获取。

获取成功后按账号保存邀请码、生成链接及获取时间，可分别复制。默认生成 `站点 origin/sign-up?aff=邀请码`，与当前 New API 上游一致：[官方前端源码](https://github.com/QuantumNous/new-api/blob/main/web/src/features/wallet/lib/affiliate.ts)。旧版 `/register`、反向代理子路径或定制页面，在「自定义注册地址」填写完整公开 URL 并保存；该 URL 仅用于拼接链接，不会携带管理凭据或被请求。已有公开参数保留，`aff` 参数更新为获取的邀请码。

也可在「手动邀请链接」填写完整链接。手动内容优先，获取不会覆盖；清空并保存后恢复使用自动链接。编辑后先保存，再获取。只允许不含密码、Token、密钥参数的公开 http(s) URL。归档账号可查看与整理本地链接，获取需先取消归档。

同域多账号各自缓存。账号身份或连接修改、资料版本冲突，以及关闭／切换后的迟到响应都有保护，旧请求不会覆盖当前资料；冲突时关闭面板后重新打开。404、认证失效及网页／验证码响应分别提示，失败保留原链接，不保存原始响应。

普通 JSON 备份只包含手动链接和自定义注册地址，自动获取缓存不随备份导出。旧备份继续兼容；恢复后按需要再次点击获取。

本轮通过本地合成站点验证，真实站点版本和管理令牌权限尚未验证。运行部署尚未更新。

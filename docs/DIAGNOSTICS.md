# 查询诊断（阶段 1）

账号详情下方的「查询诊断」显示最后一次手动点击测试或刷新产生的结果。它不是监测面板，没有轮询、后台探测或自动重试。展开面板、复制报告和切换页面均不会请求供应商。

## 使用

1. 选择账号，点「测试连接」或「刷新余额」。测试读取并解析余额，但不写入余额或历史快照。
2. 查询结束后查看「查询诊断」。失败自动展开，成功可手动展开；诊断保存到本机，重启后仍可查看。
3. 查看失败类型和下一步提示，然后按需手动修改配置或重试。
4. 提交 Issue 前点「复制脱敏报告」。自动复制不可用时，会出现只读文本供手动复制；不会替你上传报告或创建 Issue。

## 耗时的意义

| 阶段     | 实际边界                                                                                                 |
| -------- | -------------------------------------------------------------------------------------------------------- |
| DNS 解析 | 部署服务器的系统 DNS，或显式配置的 Cloudflare DoH；检查全部地址后固定目标 IP。字面 IP 显示「无需解析」。 |
| 建立连接 | HTTP TCP 连接；HTTPS 包含 TCP 和 TLS 验证。                                                              |
| 等待响应 | 连接完成到收到响应头。包含网络时间，不等于站点内部处理时间。                                             |
| 读取响应 | 读取受限正文并校验 JSON。                                                                                |
| 余额解析 | 按平台模板确认字段、查询口径与单位。                                                                     |

未执行的阶段为 `not-run` / `null`，不是零毫秒；真正完成的零耗时允许显示。单调时钟测量阶段，10/20/30 秒总截止时间由原有查询配置决定；不会给每阶段重新分配超时。总耗时还包含配置、安全检查和保存开销，阶段和总时间不保证完全相等。

## 区分问题

- `network`：DNS、连接、证书、等待响应或响应中断/超时。
- `auth`：HTTP 401/403 级拒绝；也可能是站点防护，不仅是密钥失效。
- `compatibility`：404、拒绝跟随的重定向、非 JSON、超大正文或不能按模板确认余额。
- `rate-limit`：HTTP 429，稍后手动重试。
- `service`：其他 HTTP 异常或 HTTP 200 内业务拒绝。业务拒绝不能直接判断密钥无效。
- `security`：禁止地址或私有网络限制。云元数据始终禁止，普通私有站点仅由部署允许列表显式放行。
- `configuration`：缺少凭据或查询配置不正确；可能尚未执行任何网络阶段。

余额查询失败保留上次金额，不能当作零余额。连接测试不改变最近余额同步状态；详情中的「最近查询」沿用余额同步结果，诊断中明确写「连接测试」或「余额查询」。手动余额或档案编辑不会抹去上次诊断，它是标有时间与当时平台的历史查询结果。

## 隐私合同

诊断版本为 1，仅保存/复制：固定的平台与操作类型、UTC 时间、超时/DNS 模式、阶段状态/耗时、固定分类/错误码、HTTP 状态。新增可选 `routeMode: direct | proxy`，只描述这一次实际使用的查询线路；不包含代理地址/认证。旧报告无此字段时显示「线路未记录」，不推断历史线路。

不含：站点/账号名称、账号 ID、地址/域名/路径/IP、DNS 答案、用户 ID、密钥/请求头/响应头、原始错误、正文或余额。前后端均用递归白名单重新校验，未知字段被移除。JSON 账号备份不包含诊断；它不是余额快照。

诊断无法凭空解决 第三方站点 的 DNS/直连问题。真实余额成功仍未确认；本轮没有发送真实凭据，没有自动启用 DoH，没有加入或接管代理。

## 验收

`npm test`、`npm run typecheck`、`npm run build`、`npm run test:diagnostics`。

浏览器脚本必须在生产构建后执行，使用独立端口与临时库。报告和截图在 `output/playwright/diagnostics`，所有截图余额均为夹具，不是真实账号。

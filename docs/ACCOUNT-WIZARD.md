# 新增站点向导

点击「添加站点」后依次完成五步；现有档案的「编辑」仍是原表单，不会强制重新接入。

## 1. 平台与查询口径

主动选择查询类型，不根据域名猜测：

- **手动记录**：任意网站，不需要凭据和接口测试。
- **New API · 账户余额**：用户管理令牌与站点要求的用户 ID，查询整个账户。模型 API Key 不能当作管理令牌。
- **New API · 令牌额度**：模型 API Key，只查该令牌，不代表账户余额。令牌金额不并入 USD / CNY 账户合计。
- 其他模板或自定义字段映射沿用各自的接口口径；SiliconFlow 仅旧接口兼容，不保证官方账号可用。

## 2. 地址与凭据

填写名称、网站地址、接口根地址与凭据。凭据允许暂时留空，稍后再补充；真正点击测试时才会检查是否具备所需凭据。

- 预设平台留空接口根地址时使用预设地址；否则使用 API 地址或网站地址。管理根地址与模型 /v1 地址应区分。
- DeepSeek 在此选择测试币种，必须匹配接口实际返回的币种，不会换汇。
- 「高级连接设置」收纳 API 地址与 10 / 20 / 30 秒超时。
- 自定义仅允许同源 GET 路径和声明式字段映射，不执行 JavaScript；密钥只填凭据字段，不放在网址里。
- 返回上一步保留输入。切换平台会清空凭据、接口根地址及用户 ID，避免误把上一平台的密钥发送到新平台。

## 3. 点击测试

点击「测试连接」才发起一次请求；不会因下一步、保存或停留而自动查询，无自动重试。草稿测试经过服务端登录、CSRF、超时和地址限制，不由浏览器直接请求供应商。

测试不创建临时账号、不保存凭据、不新增余额快照，也不保存草稿诊断。关闭向导会丢弃草稿。测试成功读到的金额仅供确认，**保存时初始余额仍为未知**，之后需要自己点击刷新。

测试或保存进行中不能关闭向导，需等待结果或所选超时结束；完成后可关闭并丢弃草稿。不会因重新打开而暗中继续新查询。

失败可展开「查询诊断」查看阶段耗时，并复制脱敏报告；复制不会上传或新增请求。修改地址、凭据、查询映射或影响解析的币种后，旧测试失效。修改名称、分组等档案信息不要求重查。

也可以点击「暂不测试，继续」。最终保存前须明确勾选「我确认保存尚未验证的配置」，以免误认为已经验证成功。

## 4. 确认单位

- New API 先测试原始配额。默认保留「配额」或「令牌配额」，不计入货币合计。
- 确认站点的换算规则后，勾选「我已确认换算系数」，填写正数系数；换算预览只使用本次测试的原始配额，采用精确十进制，不重新请求。
- OpenRouter 固定 USD，SiliconFlow 旧接口固定 CNY；DeepSeek 使用所选 CNY / USD。自定义单位不跨站混加。
- 手动模式可以填写初始余额；留空代表未知，填 0 是明确的零余额。
- 勾选「我已确认余额单位与查询口径」后继续。更改口径、单位或换算规则会撤销确认，需再次确认。

## 5. 保存

核对网站、口径、单位和本次验证状态，再填写分组、标签、可选阈值。控制台 / 充值 / 文档入口与备注放在可展开区域。

「保存站点」只创建本地档案，并在服务器加密保存凭据。不会自动查询、后台轮询、启用 DoH 或代理。单位未确认或未验证配置未明确接受时，不能保存。

未保存草稿不进入 JSON 备份，测试诊断也不会被带进新账号。多账号可使用相同网站地址，彼此独立。

# 地图与批量管理

> 第四阶段功能说明；最终验收状态见 STATUS.md。本页不是测试通过的证据。

## 在地图上找站点

- 搜索名称、账号别名、网址、分组或标签。地图保留其他账号并轻度淡化，匹配数、汇总与「刷新余额」范围只算匹配项；列表只显示同一批匹配项。
- 「定位」会依次聚焦匹配账号并展开其分组。没有匹配时保留地图，方便修改搜索，不生成假节点。
- 分组名称在岛内顶行居中，点击组名聚焦，折叠按钮收起/展开。分组索引同样保留；折叠只隐藏账号，保留原岛及计数，切换地图/列表时保留折叠状态，刷新页面后恢复展开。
- **整组移动：** 拖住标题/握柄移动整座岛，组内站点同步跟随，松手才保存。镜头不随拖动跳位；Esc、指针取消、在地图视口外放手均取消。保存失败恢复原布局；其他页面已修改布局时拒绝过期写入并重新读取。
- 标题获得键盘焦点后：方向键移动 24 个世界坐标单位，Shift + 方向键移动 100；Home 恢复该组自动布局，Enter/空格聚焦。折叠岛、触屏和减少动效下同样可用。空白处仍平移地图，不是移动分组。
- 组位置按名称独立保存为有界四向世界坐标（±1,000,000），更新余额、添加另一分组不会重排已经摆放的岛；不做持续模拟或自动避让，允许自行重叠。缩略图和定位使用新坐标。组内节点仍是稳定网格，不是每个节点自由摆位。
- 新增/编辑站点的分组菜单列出已保存分组（包括归档账号的组），也可选「新建分组」填写名称。随站点保存才创建，不生成空岛。新建名称不可空白，最多 50 字。
- v3 JSON 备份增加可选 `groupPositions`，导入先校验重复名称/未知分组/非法坐标，预览不写入，恢复位置与账号/快照处于同一事务。旧版不含位置的备份仍可导入，不覆盖现有布局；导入含位置的备份会替换已保存的位置偏好。
- 拖动站点调整组内顺序，或放到另一岛上改变分组。落点提示表示插入位置；不是自由摆位，仍是稳定网格。拖动空白处平移地图，轻点站点打开详情。Escape、指针取消或落在岛外不会保存。保存失败保持原位置，并提示重试。
- 顺序与分组保存在 SQLite 和备份中。只更新分组/顺序元信息，不改余额、快照或凭据。查询忙碌时禁止移动涉及的分组，过期档案会拒绝写入，避免覆盖其他页面的修改。
- 键盘：聚焦站点后按 Alt+M（或选中后点击「移动所选站点」），通过下拉菜单选择目标分组与插入位置，点击「保存位置」。Escape 取消；不便拖拽时同样可以操作。
- 收藏/归档仅提交对应字段，不带旧分组。编辑器保存带版本检查，遇到冲突请关闭编辑器、刷新后重新编辑；旧版 API 客户端全量 PATCH 应携带 `expectedUpdatedAt`，否则没有并发预检。
- 搜索、排序、余额更新或折叠不改坐标。新增、删除、改分组属于结构变化，可能重排受影响群岛。归档不删除档案，档案范围外的节点隐藏，坐标仍按全量档案计算。

## 导航大地图

- 画布可向四周平移。点击画布后按住空格加左键拖动，可从站点或分组上开始平移；中键也可以。松开空格、Esc 或窗口失焦会结束抓手。按钮、站点和组标题获得焦点时，空格保留原有激活操作。
- 整岛可保存到负坐标，向左或向上移动不再卡在零点；「显示全部站点」和定位小窗包含这些位置。存储坐标仍有 ±1,000,000 的有限保护范围。
- 桌面地图与账号详情使用相同高度，上下框线对齐，详情内部滚动。手机继续使用底部详情面板。
- 左下工具：缩小、缩放比例、放大、全图、定位小窗开关。
- 小窗显示群岛轮廓、当前视口与选中账号；点击空白处或拖动移动视口，点击群岛聚焦分组。聚焦小窗后，方向键平移，Shift + 方向键移动更远，Home 返回全图。
- 岛屿内部也能起拖，松手不误触分组聚焦；轻点仍可聚焦，键盘和辅助技术激活保留。
- 网格随缩放按层级抽稀，远景不过密。不使用后台模拟、循环粒子或网络请求。
- 平移/缩放/拖拽活动通过稳定引用与 DOM 标记更新，不在每次开始/结束时重建整张 React 节点树；只有实际跨越详情层级等状态变化才更新节点。忙碌时纸面擦显清空并取消动画，静置不保留循环。
- 200/500 档案可从全图导航。缩远时金额和新鲜度收起，放大或用列表看清；岛大小不编码金额，不显示虚构请求连线。
- 较多分组采用确定性二维布局，各列按实际最大岛宽排布；全图及滚轮/按钮的最低缩放按实际地图与视口适配，避免混合大组或独立小组越界。
- 触屏、关闭装饰动效或系统减少动效时镜头直接定位，平移/缩放/键盘功能不变。手机默认列表，也可切到地图。

## 批量整理

1. 切换列表，点击「批量管理」。勾选账号，或选择当前结果。每批最多 500 项；结果超过 500 时全选仅选择当前排序前 500 项。
2. 工具栏显示已选数量。改变搜索/分组/币种/收藏/档案范围，会移除被隐藏的选项；切换地图/列表保留仍匹配的选项。退出批量管理、离开站点页或退出登录会清空。
   - 弹窗打开后，如果异步档案更新使当前范围变化，会禁用提交并提示重新确认。点击「重新确认当前范围」后再提交，不会偷偷对原来已隐藏的账号操作；没有剩余账号时只能取消并重新选择。
3. **修改分组：** 选择已有分组，或填写新名称（1–50 字），确认保存。
4. **编辑标签：** 添加保留旧标签并去重；移除只删除指定标签；替换覆盖全部原标签，留空替换即清空，确认面板会明确提醒。每个账号最多 12 标签、每个最多 24 字。任一账号合并超限，整批不保存。
5. **归档：** 在显示所选范围的确认面板确认后保存。归档保留余额、历史和查询凭据；在更多筛选选择「已归档账号」，批量取消归档即可恢复。

所有操作只改分组/标签/归档状态，不查询、不删除账号、不改余额、快照来源、记录时间或凭据。服务端在事务内预检全批，任一账号不存在/正在查询/输入非法时全批拒绝。提交失败保留选择；若发生断网，页面不能确认提交是否到达，请重新读取后核对，不重复盲点。

## 开发验收

- `npm test`：包括稳定几何、网格、小窗投影、选中范围和真实 SQLite 批量事务/API 回归。
- 可选地图专用浏览器回归：PowerShell 执行 `$env:RELAYDOCK_MAP_GESTURES='1'; npm test; Remove-Item Env:\RELAYDOCK_MAP_GESTURES`。仅临时地图夹具，覆盖长按取消、视口外放手、隐藏排序、500 节点活动更新与 Canvas 清理。
- `npm run typecheck`、`npm run build`。
- `npm run test:group-layout`：当前生产构建、临时数据库，验收新增/编辑分组、整岛移动/取消/回滚/冲突/键盘/触屏及浅深响应式截图；本流程不会发出余额查询。
- `npm run test:management`：当前生产构建、无环境文件的临时运行目录、临时数据库、白名单环境。检查搜索/折叠/小窗、批量、响应式、触屏/减少动效、200/500、空闲与无供应商查询，产物在 `output/playwright/management/`。
- 生产用户数据不用于验收。性能数字仅代表本机夹具，不等于所有设备的 FPS 或容量承诺。

不会自动启用 DoH 或查询代理；可选显式配置见 [查询与网络设置](QUERYING.md)。没有轮询或重试。第三方站点 的真实余额查询成功仍未确认，不把 UI 验收当作站点网络问题已解决。

## 保存后的聚焦与分组改名

- 新增站点或成功移动站点后自动选中并居中该账号；目标分组会展开。只清除会隐藏目标的筛选，仍然匹配的筛选不变。列表模式会滚动到目标账号。
- 待保存的移动不提前聚焦；保存失败恢复布局和原选中状态。普通余额写入、整岛拖动和单纯数据刷新不会重新适配全图，也不会造成镜头随意漂移。
- 地图标题旁的「改名」与工具栏的分组改名入口都会更新组内所有账号，包含归档账号。名称为 1–50 字；目标重名拒绝，不自动合并。
- 分组改名在事务内保留账号 ID、余额快照、凭据、排序、位置以及其他元信息，同步迁移分组筛选与折叠状态。布局已被其他页面修改时拒绝旧版本，刷新后再操作。
- 同一平台、同一域名可以保存多个独立账号。每个账号有自己的 ID、别名、凭据、用户 ID、余额与历史；不会按域名自动去重。同币种会按账号合计，重复录入同一个钱包也会分别计入，请用别名区分。

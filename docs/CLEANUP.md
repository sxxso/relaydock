- 旧浏览器截图、trace.zip、失败产物及重复测试日志。
- `output` 内一次性诊断/探测/汇总脚本；不是正式功能或可复用测试。

## 为什么这些保留

| 路径                           | 用途                                                              |
| ------------------------------ | ----------------------------------------------------------------- |
| `src/`、`public/`              | 应用源码与静态资源；空 public 也保留，因为容器构建需要这个目录    |
| `tests/`、`scripts/`           | 可重复运行的回归测试、隔离运行工具、初始化脚本，不是历史日志      |
| `data/`                        | 真实数据库、SQLite WAL/SHM 和加密主密钥；删除会丢账号、历史或凭据 |
| `.env.local`                   | 本机管理员及查询部署配置；不能删、不能公开                        |
| `node_modules/`                | 启动、构建和测试需要的依赖；不是备份文件                          |
| `.next/`                       | 正在运行的开发服务和已验收的生产构建；此轮不清，以免预览中断      |
| `package-lock.json` 和配置文件 | 可复现安装、TypeScript、Next、样式与测试配置                      |
| `compose.yaml`                 | Docker 主部署文件                                                 |
| `docker-compose.yml`           | 显式代理覆盖文件，不是重复的主部署文件；组合用法见 QUERYING       |
| `docs/`、`CONTRIBUTING.md`     | 用法、部署、设计合同及贡献规则，便于后续开源维护                  |
| `.learnings/`                  | 少量安全清理/工具纠错记录，防止重复误操作                         |
| `output/` 中保留产物           | 最新四套验收、小体积历史汇总及仍有用的脱敏网络诊断；不是站点数据  |

## 安全检查与以后清理

本轮删除前核对绝对路径均在项目指定输出范围，拒绝符号链接/目录联接以及疑似数据库、密钥和环境文件，并复核待删文件未改变。没有递归删除整个项目或结束未知进程。

`output/` 由测试脚本再生成，已被 Git/Docker 忽略；后续需要时重新跑相应测试。不要拿旧验收结果当新修改的通过证据。若要清理 `.next/` 或重装依赖，先确认本项目服务停止，并与数据库/密钥目录明确区分。
